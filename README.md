# ⚡ 竞技场 - 生存射击

一个基于 **HTML5 Canvas** 的单文件网页生存射击游戏（类《吸血鬼幸存者》风格）。
所有代码（HTML / CSS / JS）内联在单个 `hh.html` 中，**零外部依赖**，浏览器打开即可玩。

## 🎮 在线试玩

> GitHub Pages 部署后生效，替换为你的实际地址：
> `https://<你的GitHub用户名>.github.io/<仓库名>/hh.html`

## ✨ 功能特性

- **枪械系统**：选择 / 新增 / 编辑 / 删除枪械，支持单发、散射、连发三种攻击模式
- **肉鸽成长**：击杀升级三选一强化——穿透、分裂、平行弹道、散射、弹射、攻速、吸血等
- **特殊属性「攻击力吸取」**：仅 Boss 掉落，被动成长，吸取概率 10% → 25% → 50%，触发后攻击力永久 +0.5
- **波次生存**：敌人与 Boss 随波次成长，每 5 波圆形 Boss、每 10 波随机大型近战 / 远程 Boss
- **Boss 战**：
  - 大型近战 Boss：扇形横摆、方形拍击、长条冲击、超长距离冲刺（带残影）
  - 大型远程 Boss：扇形散射、全屏环形散射、大量点轰炸、位移接近
  - 全部攻击带红色预警区域提示，可预判躲避
- **特效反馈**：受击火花、飘浮数字（金色 +0.5 攻击力吸取 / 绿色回血）、Boss 攻击过程动画
- **音效**：Web Audio API 程序化合成（无音频文件）
- **存档**：`localStorage` 记录最高波次与最高击杀

## 🛠️ 技术栈

- 原生 HTML5 Canvas 2D（`requestAnimationFrame` 游戏循环）
- Web Audio API（程序化音效）
- 无任何外部库、框架或网络请求

## 🚀 本地运行

直接双击 `hh.html` 在浏览器打开即可；或使用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/hh.html
```
