# ⚡ 竞技场 - 生存射击

一个基于 **HTML5 Canvas** 的网页生存射击游戏（类《吸血鬼幸存者》风格）。
核心版本为单文件 `hh.html`（HTML / CSS / JS 全部内联，**零外部依赖**，浏览器打开即玩），另提供模块化拆分版本 `modular/`。

## 🎮 在线试玩

**[点击试玩](https://qia-n.github.io/arena-survival-shooter/hh.html)**

> 注：需先在 GitHub 仓库启用 Pages 部署（见下文「🚀 部署到 GitHub Pages」）后链接才可访问。

## ✨ 功能特性

### 🔫 武器系统（6 种武器 + 解锁机制）

| 武器 | 特点 | 解锁条件 |
| --- | --- | --- |
| 🔫 手枪 | 平衡单发，无限弹药 | 初始解锁 |
| 💥 散弹枪 | 扇形粒子喷发，距离越近伤害越高，弹夹 8 | 总击杀 ≥ 100 |
| 🔫 冲锋枪 | 连续单发，每 4 发消耗 1 弹药，弹夹 25 | 总击杀 ≥ 200 |
| 🎯 狙击枪 | 单发高伤、弹速极快、红色瞄准线，弹夹 4 | 总击杀 ≥ 800 且波数 ≥ 25 |
| ⚙️ 加特林 | 7 枪口轮转、火花喷射、启动预热、移速 -30%、弹夹 500 | 总击杀 ≥ 1500 且波数 ≥ 35 |
| ⚡ 奥特曼 | 16 枪口横排高速粒子射线，无限弹药，专属成长 | 总击杀 ≥ 2500 且波数 ≥ 45 |

- **弹夹 / 换弹**：各枪弹容不同，射完自动换弹（状态栏 + 头顶弹药条显示），按 `Q` 可手动换弹
- **解锁机制**：未解锁武器首页隐藏；解锁一次永久保留（`localStorage`）；「⚙ 武器管理」需解锁奥特曼后开放
- **武器管理**：解锁后可新增 / 编辑 / 删除 / 试听武器（测试调参用）

### 🌱 肉鸽成长

- 击杀升级三选一强化，属性池随武器类型过滤
- **基础**：攻击力、最大生命、攻击范围、攻速、子弹速度、命中回血
- **特殊**：穿透、分裂、弹射、额外攻击、攻击力吸取（仅 Boss 掉落，概率 10% → 25% → 50%，触发攻击力 +0.5）、弹药扩充、换弹加速、收束扩散（散弹专属）
- **奥特曼专属**：双束射线（分裂平行光束）、灼烧射线（命中附加 2s 持续伤害）
- 升级奖励随波数成长（生命 / 攻击力），升级回满血

### 👾 Boss 体系（三阶段 + 霸体）

- **波次节奏**：每 5 波普通圆形 Boss；每 10 波随机大型 Boss 之一（近战 / 远程 / 母体）；Boss 波清场普通敌人（计击杀）
- **大型近战 Boss**：扇形横摆、方形拍击、长条冲击、超长距离冲刺（残影）、圆形蓄力冲击波
- **大型远程 Boss**：扇形散射、全屏环形散射、大量轰炸点、位移接近
- **母体 Boss**：毒液弹（中毒 DoT）、孵化虫群、毒雾区域（减速 + 持续中毒）、虫群冲击波
- **狂暴 / 二阶段**：血量 50% 触发狂暴变身演出（2.6s 可被攻击）；击杀时有 30% 概率原地进化二阶段（回满血、属性大幅提升、紫金特效、掉落属性翻倍）
- **霸体系统**：Boss 免疫击退；霸体条（血条下方金色）随受击消耗，耗尽进入 2.5s 破防静止，之后恢复
- **顶部血条 HUD**：多 Boss 同时在场全部显示（按血量从大到小）；Boss 存活期间波次冻结

### 🗺️ 地图与敌人

- 大世界地图（2.5 倍视口），相机边缘滚动 + 平滑过渡；太空化背景（漂浮陨石 / 裂缝 / 星云 / 星星）
- 普通敌人：近战 / 远程 / 自爆（移速快）/ 分裂 / 冲锋（超长距离 + 正面减伤盾）/ 治疗 / 狙击（蓄力预警线）/ 护盾
- 敌人刷新在视口外围附近，无需来回找怪

### ⚔️ 玩家

- 受击无敌帧 0.3s（防密集弹幕秒杀，半透明闪烁提示）；击退残影、受击火花、中毒 / 灼烧特效
- 弹药条 / 血条（左上固定长度）/ 等级显示

### 🎮 操作方式（桌面）

| 方式 | 说明 |
| --- | --- |
| 方式一 | 鼠标移动 + 自动射击 |
| 方式二 | `WASD` 八方向移动 + 鼠标瞄准，按住左键射击（可勾选自动开火） |

其他：`Esc` 暂停 / 退出全屏、`X` 暂停、`Q` 手动换弹、右上角 `⛶` 全屏、`⚙` 引擎调校（速度倍率 / 敌人数偏移）。

### 其他

- **存档**：`localStorage` 记录最高波次、最高击杀、已解锁武器
- **音效**：Web Audio API 程序化合成（无音频文件）

## 📁 文件结构

```

```

## 🛠️ 技术栈

- 原生 HTML5 Canvas 2D（`requestAnimationFrame` 游戏循环）
- Web Audio API（程序化音效）
- 无任何外部库、框架或网络请求

## 🚀 本地运行

直接双击 `hh.html` 在浏览器打开即可；或使用任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000/hh.html
```

## 🚀 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，将 **Build and deployment** 的 Source 设为 **Deploy from a branch**
2. Branch 选择 **main** + **/(root)**，点击 **Save**
3. 等待约 1 分钟，游戏即可通过 <https://qia-n.github.io/arena-survival-shooter/hh.html> 访问
